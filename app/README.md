# 后端架构负责人工作区

## 负责什么

FastAPI、登录/项目范围校验、业务模型/迁移、项目成员任务资料依赖风险 API、文件保存、持久 Job/Worker、建议审核事务、统一 GLM Provider 和全局装配。AI 意图理解与工具调用编排由工作流负责人实现；后端提供受权限控制的业务方法，不包办助手逻辑。

## 已实现的后端契约 v2

以下已由后端提供，格式见 [结构化任务约定](../docs/DATA_CONTRACTS.md)：

- 为 AI 项目助手和任务 AI 助理提供对话建议保存、提交者核对及提交接口；预审不写正式任务。
- 文档“提取任务”直接产生正式待审建议；每条建议独立修改、通过/驳回，所有有效项目成员均可审核，包括提交者本人。
- 从登录身份记录提交者（文档为发起提取者）、审核人和时间/结果；来源区分两个对话入口与文档，文档关联版本/原文位置，对话保留原始输入。
- 支持已有任务各项业务字段的更新建议；正式审核校验目标和版本后写入。新建及手动/AI 更新保留完整任务历史快照，不只记操作编号；首版不做回滚。
- 提供业务查询、资料检索和风险工具的注入接口；风险输入支持当前状态与候选变更，不能为分析而提前落正式依赖。
- 相关正式任务/依赖数据变化后检查风险，只保存/返回标记和提示，不定时检查、不自动改任务状态、不发外部通知。

字段和方法已同步 shared、迁移 0003、HTTP 与模块适配器；不让各组员复制不同版本的契约。旧 /queries 保留兼容，新 AI 编排入口使用 /assistant/messages 和 workflow.respond。

本目录保留原有启动路径，避免为“分文件夹”破坏已完成接口。我们同时维护 migrations/、shared/、team_modules/factory.py、公共环境配置与依赖锁；这些共享文件变更须告知受影响组员。

## 接口责任

- 前端只调 /api/v1，JSON 输入在 schemas.py，核心输出在 responses.py，运行时 /docs 为 HTTP 参考。
- 接收算法输出后验证项目、版本、锚点和候选；业务正式写入仅经 services。
- 给主 RAG 提供 FileRef / DocumentRef，保存 Block 并分配 ID。
- 给工作流提供同版本完整 Block、文档日期、实体目录、LLMProvider 和绑定项目/身份的 AssistantTools；不提供批准工具。
- 给风险模块提供同一快照事务的 Snapshot，保存 rule_version / snapshot_hash。
- 不让算法拿到业务 Session，不将开发职责变成应用内操作权限。

## 本地开发与验证

从仓库根目录按总 README 初始化自己电脑；没有公共数据库。普通 API 联调要本地账号；单测自动用临时数据。完整流程在本机另起 Worker。

```powershell
.\.venv\Scripts\python.exe -m pytest tests
.\.venv\Scripts\python.exe -m alembic check
```

改模型必须新增并检查迁移；保留现有数据和 .env。修改共享契约时通知三位算法负责人；外部模块接线只改 factory，不让每人修改 API 路由。

## 交付要求

可启动代码、README/接口文档、迁移、样例、并发/权限/幂等回归。真实模型调用单独验证，不能把离线测试称作模型质量验收。业务需求未定先按 docs/REQUIREMENTS.md 询问用户。
