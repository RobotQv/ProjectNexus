# 前端负责人工作区

本目录是前端代码的归属目录。现在有两份产物，界面同一套，用途不同：

| 目录 | 是什么 | 怎么打开 |
| --- | --- | --- |
| `prototype/项目交互原型.html` | 单文件交互原型，内置演示数据 | 双击用浏览器打开，**不需要 Node、不需要后端** |
| `web/` | Vue 3 + Vite 正式工程 | `cd web && npm install && npm run dev` |
| `tests/` | 两个自测脚本（可选） | `python tests/原型交互自测.py` |

演示与交互验收走 `prototype/`，双击即开最稳；`web/` 是需要 Node 的工程版本，
默认也是演示数据，切到「数据源 → 连接本机后端」即可做真实联调。

启动细节见 [web/README.md](web/README.md)，接口速查见 [../docs/FRONTEND.md](../docs/FRONTEND.md)。

## 已有业务需求

按已有原型/审计对接本机登录、项目/成员、任务及进度、资料与处理状态、建议人工确认、问答与来源、依赖与风险展示。支持手机视口。新页面、额外业务、细分权限或交互会改变业务含义时，先向项目负责人确认，不能把“后端有某字段”自动当作必须新增页面。

代码写在本目录，后续可内部区分页面、组件、请求封装、状态等；UI 库等内部方案由前端安排，不在本次强行创建新的界面设计。

## 已提供后端接口的交互

- AI 项目助手保留资料/任务/风险问答，也支持生成任务新建或更新建议。
- 任务管理单独提供“AI 助理”按钮与短文本对话框。两处对话的建议由提交者先核对、修正并提交，此时不改变正式任务。
- 资料库支持新文档上传；“提取任务”结果直接进入“提取结果确认”，不额外要求发起者预审长文。
- 提取结果确认按每条建议独立展示、编辑、通过或驳回，不把多条任务打包成一条审核。所有有效项目成员均可正式审核，包括提交者本人。
- 展示提交者、提交时间及来源，审核后展示审核人/时间/结果。文档建议提供“查看来源原文”，定位对应版本及正文位置。
- 任务各项业务字段可提出修改；展示正式任务历史快照，不做回滚。正式审核前不能把建议值显示成已经生效的进度。
- 风险只做标记和提示；不增加定时检查、外部通知或专职审核角色。

上述接口已补齐，见 [前端接口](../docs/FRONTEND.md) 和 [任务数据格式](../docs/DATA_CONTRACTS.md)。两个入口调用 /assistant/messages，以 entry 区分；不能用手工任务接口模拟绕过审核。真实算法未接入前可用明确标记的 demo。

## 本地怎么工作

1. 拿到完整仓库，在**自己电脑**按根 README 启动后端。
2. 在自己本地执行 seed-students，用示例登录名登录（初始密码同学号），再创建测试项目；无需组长提供远程账号。学号按字符串处理，保留前导零。
3. 启动自己的前端，将 API 指向本机 http://127.0.0.1:8000/api/v1。
4. 普通业务无需模型。资料/建议可使用后端 demo 演示，也可按根 README 启用已合入的组员模块；都需要 Worker。演示数据与真实结果必须区分。
5. 更换前端端口时，在自己 .env 的 CORS_ORIGINS 配置实际来源；不修改其他组员配置。

具体接口、请求封装、分页和示例见 ../docs/FRONTEND.md，以及本机 /docs、/openapi.json。首版不需要为后台 CLI 建号再做一个注册页面。

## 接口要求

- 请求带本机登录获得的 Bearer token；不直连业务库、向量库或智谱，不接触模型密钥。
- 编辑任务/依赖时带 expected_version；409 提醒刷新，422 显示校验问题。
- 202 只表示排队：轮询 Job，离开页面停止；失败展示 error_message/重试，不假装已成功。
- 建议确认前可编辑，确认后展示正式 target_id；重复提交不得在前端自行再建一份任务。
- 问答区分 answered/clarify/insufficient/partial；引用展示 evidence，不把模型自行生成的来源当成真实引用。
- 规则分析与人工登记风险分开展示；不自行用平均进度画成“真实完成率”或发明健康分。
- 权限以本地后端响应为准；开发职责不限制哪个组员能点击哪个功能。未确认的跨项目权限不在前端自行放开。

## 交付与边界

提交页面源码、依赖清单/锁定文件、准确的启动命令及移动端适配；开发自测自然进行，不另设自测交付物。由测试负责人验收交互和移动端效果。不提交 node_modules、构建产物、密钥或账号令牌。API 字段对不上先联系后端，不能绕过后端业务校验。
