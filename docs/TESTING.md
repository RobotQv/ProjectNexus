## 主干测试怎么运行

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check app tests migrations examples
.\.venv\Scripts\ruff.exe format --check app tests migrations examples
```

每个业务测试使用独立临时 SQLite 与临时文件目录，按 Alembic 完整迁移建库；不调用 Base.metadata.create_all 来掩盖迁移问题。模型使用 httpx.MockTransport，不会消耗真实模型额度。

当前覆盖：

- 登录错误、令牌校验、密码哈希不泄漏、统一请求编号。
- 项目/成员隔离、多类资源越权、跨项目任务引用、归档只读。
- 状态/进度、日期、空值、负责人、字段名校验。
- 两个请求编辑同一任务只允许一个成功；文本变更排索引 Job，纯进度变更不重新索引。
- 自依赖、循环、重复、跨项目边；并发反向加边；开始条件与取消前置。
- 文件名路径隔离、空文件、伪造 PDF/DOCX、大小限制、重复内容清理、原文鉴权、软删除。
- 缺模块时入库明确失败、失败重试复用 Job、租约超时失败可见。
- 演示全文解析、抽取、摘要、审核回滚、连续/并发确认幂等、删除来源后不能确认。
- 工作流结果已经提交而 Job 标记中断后的重试不重复产生建议。
- 名称/别名查询、歧义、集合查询、最新进度回源、伪造/越权证据过滤。
- 风险快照、规则结果范围校验；GLM 载荷、响应、限流、超时、断连和畸形响应。
- 初始迁移、约束保留、迁移升级/回退/再升级、模型与迁移一致性检查。

这是后端主干的回归测试，不代表真实 RAG 准确率、风险算法完整性或实际模型时延。测试中的示例规则不会被计为正式风险算法。

## 本地全流程验收

1. 初始化 `.env`、迁移、创建账号；登录并创建项目。
2. 建第二个项目和成员，验证无成员关系时不能访问。
3. 建任务 A/B，添加 A→B 的 start 依赖，验证 A 未达要求时 B 无法启动。
4. 更新 A 达标，再启动 B；用旧 version 编辑 B 得到409。
5. API/Worker 都启用 demo，上传 examples/meeting.txt，轮询到 succeeded。
6. 触发 extract，确认建议；重复确认应仍只有一个新任务。
7. 触发 summary，查看 workflow-runs 的 summary。
8. 按 task_id 查询新任务，确认返回数据库当前进度；删除资料后不能再查看来源。
9. 切回 disabled，相关算法调用必须返回不可用/失败，不能继续冒充 demo 成功。
