# 开始开发前的审计与范围决定

基线：`01_项目阶段审计与最小功能.docx`、`03_架构审计与数据字段预案.docx`。本次工作仅交付后端主干，不修改原报告、PPT 或已有 HTML 原型。

## 已明确的决定

1. 六人分模块协作，不拆成六个服务。采用 FastAPI 模块化单体，另起一个同仓库 Worker 进程。
2. 用户已明确选择“先全部使用 SQLite”。业务库不安装 MySQL；不预先选定向量数据库。
3. 后端拥有正式数据写入权。RAG / 工作流返回契约对象，规则模块读取快照；均不持有业务 Session。
4. 首版预设本地账号，组长通过 CLI 创建；没有开放注册或通用管理员后门。
5. 用户已确认所有有效项目成员均可编辑任务、上传资料、确认 AI 建议；不按开发职责或负责人/普通成员限制这些操作。保留项目范围隔离；成员管理、名称与归档仍沿用负责人操作，未实现更细的组织权限。
6. 用户已确认使用智谱 BigModel 官方 API，预留官方通用端点和 `glm-4.7-flash`。通过环境配置可更换，不在代码中硬编码真实密钥。

## 审计要求 → 当前实现

| 要求 | 主干实现 / 边界 |
| --- | --- |
| 项目、成员、任务业务 | 真实 SQLite CRUD、软删除任务、负责人校验、筛选与分页 |
| 状态/进度、日期与版本一致 | 输入校验 + 数据库约束；任务版本冲突；UTC 记录 / 项目本地日期 |
| 双侧依赖关卡 | 保存所有 P0 字段、创建/编辑查环、开始操作关卡校验 |
| 依赖风险判断 | Snapshot / AnalysisResult 契约与评估记录已实现；正式判定由风险负责人提供 |
| 文档入库 | 原文件保存、哈希去重、Job、解析/索引状态、重试、源文件鉴权 |
| Block / Chunk 可追溯 | Block 由主干保存并分配 ID；Chunk / 向量元数据由主 RAG 模块持有，引用须绑定 Block 和版本 |
| 共用全文 | parse 只做一次，失败重试复用已就绪的 Block；工作流接收完整 Block 与文档日期 |
| 主 RAG | parse / ingest / retrieve / delete 接口、失败可见；正式 DOCX/PDF、Embedding、检索等待组员接入 |
| 轻 RAG | 同事务创建同步 Job、任务/成员目录、候选回源过滤；提供关键词降级，不冒充语义搜索 |
| 工作流 | 持久 Run、提取/摘要两种入口、待审建议、来源校验、人工确认事务 |
| 问答编排 | 显式/关键词路由、单实体与集合分离、歧义候选、事实/证据/规则结果、可选 LLM 表述 |
| 统一模型出口 | GLM 非流式 Provider、可配置端点、预算、超时、并发限制、错误脱敏 |
| 背景执行恢复 | 数据库 Job、单任务消费、心跳租约、过期可见失败、人工重试、发布结果幂等 |
| 审计记录 | 关键业务操作 AuditEvent，QueryRun 和 AnalysisRun；不记录密码或模型密钥 |

## 有意不扩张的部分

- 不实现其他人的真实 RAG 检索、分块质量优化、实体语义消歧、抽取提示词、风险算法和影响路径算法。
- 不把 `blocked` 加进任务状态，不用简单平均进度声称项目真实完成百分比，不做“健康分”。
- 不引入 Redis / Celery、微服务、长连接推送、复杂多租户组织结构；前端轮询 Job 即可。
- 不实现 OCR；扫描 PDF 由正式解析模块明确报“不支持/无正文”，不能空成功。
- 不覆盖旧文档。首版重传采用新 Document ID，版本字段保留供扩展；已有来源不会跳到另一份正文。
- 不把规则 Finding 与人工确认 RiskItem 合并；没有自动修改已有任务的建议类型。
- 目前 Query Router 是透明的关键词规则，复杂自然语言识别留待开发集验证与扩展。API 支持前端直接给 route / task_id / filters，避免依赖猜测。
- 不实现流式模型输出、Embedding Provider 或向量库部署。聊天模型 Provider 是共用出口，Embedding 需要按选定方案另接。

## 需要后续确定、但不阻塞主干的事项

- 智谱官方 API 的本地密钥配置、账户可用额度与实际调用验证；密钥不发到聊天或仓库。
- 用户已授权主 RAG / 轻 RAG 负责人协商 Embedding、维度、向量库与集合版本；在各自目录记录选型，不应各自复制业务库。
- 真实解析与索引的耗时、最大文本体积、模型上下文分批策略；当前上传上限默认 20 MB，LLM 输入有独立预算。
- 风险负责人冻结 `rule_version / reason_codes`，确认日期缺失、取消前置、进度关卡、完成冲突的期望输出。
- 测试负责人准备开发集与冻结集，记录可复现指标。仓库中的主干回归测试不能代替文档中的算法测评。
- 资料保留 / 真正销毁策略若要改变，先确认；课设协作编辑权限已确认，不新增更严格的业务角色限制。

当前交付可支撑 M1 接口冻结和 M2 普通业务联调；真实 AI 能力验收必须等组员模块接入后再进行。
